# Aavaran side panel — the Canva handoff

The UI is being redesigned **from scratch**. Colour scheme, mood, type, layout — all of it
is Jinshri and Vansh's to choose. This file is not a style guide; it records the only
things the design has to satisfy to be buildable, and nothing else.

**Send them:** `Aavaran-Canva-Template.pptx` (import into Canva) or the `.pdf` to read on a
phone, plus `message-to-designers.txt`. Regenerate with
`python3 design/build-canvas-template.py` — never hand-edit the file.

---

## The size, which is the whole point of the template

**800 × 1800 px per page.** The real panel is **400 × 900 CSS px**, so the canvas is the
panel at **2×**. Designing at 2× means every measurement halves cleanly into CSS and the
rebuild reads values off the design instead of estimating them.

⇒ **Every number should be even.** An odd one lands on half a pixel.

Canva fallback if the import misbehaves: **Custom size → 800 × 1800 px**.

## The four constraints that survive a redesign

1. **One screen per page, page names kept as they are.** There are 13 screens because the
   code reaches 13 states; the names are how a design gets matched to the screen it
   belongs to. Longer than one page → continue on `<name>-cont`.
2. **The panel is user-resizable, about 320–500 CSS px** (640–1000 on the canvas). Design
   at 800, then sanity-check at 640. Nothing may depend on a fixed width, and anything
   side-by-side has to be able to stack.
3. **It scrolls, and only the top bar can pin.** Whatever they put at the top, its height
   is a tax on every screen.
4. **Fonts must be vendored into `extension/fonts/`, never linked.** A tool whose headline
   is that nothing leaves your machine must not fetch fonts.googleapis.com on first paint.
   So the typeface they pick has to be one we can legally ship as a `.woff2`.
   ⚠ Canva has no Geist; whatever they use in Canva is a stand-in for layout only.

## The 13 screens

`0-launch-screen` · `1-idle-server-ready` · `2-server-offline` · `3-scan-result` ·
`4-run-complete` · `5-settings-open` · `6-scan-ambiguous-field` ·
`7-server-unreachable-repo` · `8-scan-only-package` · `9-model-not-installed` ·
`10-page-unreadable` · `11-model-downloading` · `12-scan-only-but-server-up`

Current screenshots are in `reference/` at 2×, regenerated by
`node scripts/panel-shot.mjs`. **Reference, not a target** — they are what is being
replaced.

## Handing it back

PNG of each page at **1:1, no scaling**, filename = page name. The Canva edit link too, so
exact x/y/size can be read off the position panel. Anything they wanted to do and could not
do in Canva, in a note.

**One thing to ask them not to rewrite: the wording.** Lines like *"would be withheld"* and
*"nothing was transmitted"* are precise claims about what the software does. If a line
reads badly, flag it and the claim gets fixed properly.
