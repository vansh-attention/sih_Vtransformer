The only thing that has to be right is the size:

Two small things that make it buildable:

  One screen per page. If a screen runs longer than the page, continue on a new
  page and add -cont to the name.

  Keep the page names as they are. There are 13 screens and that is how each
  design gets matched to the screen it belongs to. Page 1 lists them.

The dashed grey lines on each page are just guides showing where the current
margins sit. Move them, ignore them, delete them.

Send back: a PNG of each page at 1:1 (no scaling), filename the same as the page
name. The Canva edit link too, if you can.
